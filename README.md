# 萌獸冒險：星光道館之旅

仿照劍盾玩法的對戰養成遊戲，萌獸全部是原創角色。

## 怎麼開始玩

| 方式 | 說明 |
|---|---|
| 在這台電腦玩 | 直接雙擊 `index.html`，用瀏覽器開啟 |
| 傳到平板或手機 | 把 `dist/萌獸冒險.html` 這**一個檔案**傳過去，用瀏覽器開啟 |
| 線上版 | https://claude.ai/artifact/KqFViwYdQmYD5rB6aPNQdN（目前只有你的帳號能開，要給孩子玩請用頁面上的「分享」） |

遊戲會自動存檔在瀏覽器裡。換裝置時，到「⚙️ 設定 → 複製存檔碼」，再到另一台「貼上存檔碼」。

## 遊戲內容

- 3 隻御三家、58 種原創萌獸、18 種屬性、約 150 個招式、20 種特性
- 10 個地區、8 座道館、對手阿光、冠軍盃
- 捕捉、升級、進化、學新招式、營地（摸摸、煮咖哩加感情）、特訓場（能力 ★ 加成）
- 對戰旁邊的「屬性小幫手」會即時顯示：對手怕什麼、你的招式效果如何、要小心哪些攻擊
- 館主會「星光巨大化」，玩家每場道館戰也能用一次

## 難度（可在設定中隨時更改）

- **輕鬆**：對手比較隨機
- **標準**：對手會挑效果好的招式、被剋制時換人、會用傷藥
- **挑戰**：對手更聰明、等級 +2

## 給想修改的人

| 想改什麼 | 檔案 |
|---|---|
| 萌獸能力、外型、招式學習表 | `js/data/species.js` |
| 招式威力與效果 | `js/data/moves.js` |
| 地區、訓練家、館主隊伍、商店道具 | `js/data/world.js` |
| 屬性相剋表、小口訣 | `js/data/types.js` |
| 經驗值倍率 | `js/engine/mon.js` 的 `G.EXP_MULT` |

改完後執行 `node tools/build.mjs`，會重新產生 `dist/` 裡的單一檔案版本。
`dev/gallery.html` 可以一次預覽所有萌獸的造型（需要用本機伺服器開啟）。
